This is the code and data to reproduce the figures for the manuscript entitled "Triple Oxygen and Hydrogen Isotopes of Soil Water Across Climates, Seasons, and Depths," submitted to G-cubed by Kelson et al. in 2026.

The .csv files titled mw.csv and sw.csv are water isotope data for meteoric water and soil water, respectively. I have also included an excel file with the same water isotope data and associated metadata (using the template fromwaterisotopes.org). I have also included an excel sheet that gives the indivial analyses of samples and reference materials, in run order, measured for d18O and d17O via IRMS.
